# 项目收获

经过几个月的开发与调试，我们的收获颇丰，主要有以下几点：

1. **调试器开发能力提升**：在项目开发过程中，我们学习了 GDB/MI 协议、DAP 协议和 VS Code 扩展开发，把调试器从一个命令行脚本做成了完整的 VS Code 插件。以前调试器对我们来说是一个黑盒工具，现在可以按自己的需要去改造它，极大提高了我们阅读和修改系统软件代码的能力。
2. **对 Rust 异步机制的理解加深**：为了追踪异步函数的执行过程，我们深入研究了编译器生成的异步状态机，理解了 poll、`__awaitee` 等机制。通过做调试工具，我们对 async/await 的理解比单纯写代码深刻了很多。
3. **对操作系统调试的认识提升**：从 rCore 到 StarryOS 再到 Async-os，我们经历了同一套调试方法在不同系统上失效的过程，认识到符号表切换和特权级边界才是 OS 调试的核心难点，以前在课上学到的概念在真实系统里都有了直观的体会。
4. **测试与重构能力提升**：移植 OS 调试功能时，我们把状态机逻辑重构成了纯函数式实现，并补写了 79 条断言的单元测试，测试发现了多处手工调试找不到的 bug。经过了这次重构，我们意识到了自动化测试对于系统软件开发的重要性。
5. **工程化能力提升**：把工具从「能用」打磨到「好用」的过程中，我们完成了插件架构设计、图形界面开发、调试配置设计和文档撰写等一系列工作，积累了从原型到产品的完整经验。
6. **团队协作能力提升**：项目期间团队里有新成员加入，通过分工协作和复现带教，新成员快速融入了开发流程，团队也形成了自己的分工体系。
